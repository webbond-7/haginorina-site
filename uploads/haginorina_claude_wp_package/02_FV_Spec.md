# FV Spec：ファーストビュー実装仕様

## 1. FVの目的

サイト訪問直後に、以下を一瞬で伝える。

- はぎのりな様の公式サイトであること
- 明るくやさしいポップな世界観
- 表現者としての芯と親しみ
- 活動紹介・写真・ニュース・SNSへの導線

## 2. レイアウト方針

### PC

- 左側：コピー・名前・リード文・CTA・SNS
- 右側：メインビジュアル写真
- 上部：ロゴ + ナビゲーション
- 背景：白〜淡いグレーをベースに、赤・黄・淡色の丸図形、ドット、曲線装飾

### FV内の優先順位

1. 写真
2. 名前「はぎのりな」
3. 肩書き「フリーの役者 / たまにモデル」
4. CTA「最新情報をチェック」
5. ナビゲーション
6. SNS
7. 装飾

## 3. コピー

### ロゴ

`Haginorina`  
`Official Fan Site`

### 肩書き

`フリーの役者 / たまにモデル`

### メインタイトル

`はぎのりな`

### リード文

```
表現することが大好きです。
舞台や映像、いろんな場所で
皆さんと出会えますように。
```

### CTA

`最新情報をチェック`

### ナビゲーション

- 活動紹介
- Photo / Gallery
- News / Info
- Contact & SNS

## 4. 写真エリア

### 仕様

- PCでは右側に大きく配置
- 角丸の大きいフレーム
- 写真の顔周りは欠けさせない
- 赤い衣装が世界観のメインカラーと連動するように見せる
- 写真上に装飾を乗せる場合は透明度を下げ、人物の顔にはかけない

### 推奨CSS

```css
.hero-visual {
  border-radius: 48px;
  overflow: hidden;
  position: relative;
}

.hero-visual img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```

## 5. 装飾ルール

### 使用する装飾

- 大きな円
- 小さなドット
- ドットマトリクス
- リング
- 斜めの丸棒
- 淡い円形グラデーション

### 配置方針

- 四隅に大きめの円を置く
- テキスト周辺は控えめにする
- 写真周辺には中〜小サイズの装飾を重ねる
- 装飾は背景として扱い、コンテンツより前に出すぎない

### z-index

1. 背景色
2. 背景装飾
3. 写真・テキスト
4. CTA・ナビ
5. 重要な浮遊バッジ

## 6. CTA

### 見た目

- 黄色の丸角ボタン
- 右側に矢印
- 軽いシャドウ
- hover時に少し浮く

### 推奨CSS

```css
.hero-cta {
  display: inline-flex;
  align-items: center;
  gap: 20px;
  padding: 18px 36px;
  border-radius: 999px;
  background: #F4D35E;
  color: #222222;
  font-weight: 700;
  box-shadow: 0 12px 24px rgba(230, 57, 70, 0.12);
  transition: transform .3s ease, box-shadow .3s ease;
}

.hero-cta:hover {
  transform: translateY(-3px);
  box-shadow: 0 16px 32px rgba(230, 57, 70, 0.18);
}
```

## 7. アニメーション方針

### 推奨

- 装飾円がゆっくり浮く
- ドットが淡くフェード
- 写真スライド
- CTA hover
- scroll cue

### NG

- 派手なバウンド
- 高速アニメーション
- 文字が読みにくくなる動き
- 写真の顔周りを邪魔する動き

## 8. 将来的なスライド運用

FV写真は複数枚スライドできる構造にする。

### 想定

- WordPress管理画面でFV画像を差し替え
- 季節ごとに装飾色を変更できる
- 画像に合わせてアクセントカラーを変えられる
- スライドインジケーターを表示

## 9. アクセシビリティ

- 文字と背景のコントラストを確保
- nav / CTA はキーボード操作可能にする
- 装飾画像は `aria-hidden="true"` 扱い
- メイン写真には代替テキストを入れる
