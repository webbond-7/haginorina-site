# Design.md：はぎのりな様 公式サイト デザイン方針

## 1. サイトの目的

はぎのりな様の活動・写真・出演情報・SNS/お問い合わせ導線をまとめた公式Webサイト。

単なるプロフィールサイトではなく、訪れたファンが「また見に来たい」と感じる、明るく、やさしく、少し非日常感のある公式ファンサイトとして設計する。

## 2. コアコンセプト

**Feel the Boundary, Transform the Ordinary.**  
境界を感じて、日常を変えていく。

### コンセプトの解釈

- 日常と非日常のあいだに立つ存在
- 舞台・映像・モデル活動を通じて、見る人の感情を少し揺らす
- 素朴さや静けさの中にある、小さな魔法を表現する
- 「ふつう」と「ヘン」のあわいを肯定する

## 3. デザインテーマ

**チューリップと風が吹く、明るくやさしいポップパーク**

チューリップそのものを大量に配置するのではなく、  
「はぎのりな様がチューリップ畑に咲いている」ような、明るく軽やかな世界観を作る。

## 4. 印象設計

### 目指す印象

- 明るい
- やさしい
- 親しみやすい
- 公式感がある
- ポップだが子どもっぽくない
- 清潔感がある
- ファンが何度も訪れたくなる

### 避けたい印象

- 装飾過多で読みづらい
- 安っぽい
- アイドルサイトに寄りすぎる
- 雑貨サイトっぽくなりすぎる
- 写真より装飾が目立つ
- スマホで情報が詰まりすぎる

## 5. カラー方針

### メインカラー

チューリップレッド  
`#E63946`

役割：
- はぎのりな様の「芯のある感性」
- 表現者としての情熱
- 視覚的な主役感
- 名前・アクセント・重要CTAに使用

### アクセントカラー

スプリングイエロー  
`#F4D35E`

役割：
- 春らしさ
- 元気さ
- 親しみやすさ
- ナビゲーション、ボタン、装飾円などに使用

### ベースカラー

ホワイト  
`#FFFFFF`

役割：
- 清潔感
- 余白
- 写真や赤・黄の色を活かす土台

### 補助カラー

- Soft Warm Background: `#F7F6F2`
- Text Main: `#222222`
- Text Sub: `#666666`
- Pale Yellow: `#FFF3C4`
- Pale Red: `#FFE5E2`
- Border Light: `#EFEAE2`

## 6. フォント方針

### 日本語ベース

推奨：
- UD丸ゴ_ラージ
- Rounded M+
- 源ノ角ゴシック
- Noto Sans JP

方向性：
- 丸みがある
- 可読性が高い
- ポップモチーフと相性が良い
- 色や装飾に負けない

### 欧文・ロゴ・装飾

推奨：
- Baloo 2
- Nunito
- Quicksand

方向性：
- 丸み
- リズム感
- 親しみ
- 少しブランド感のある軽やかさ

## 7. ビジュアルモチーフ

### 1. ドット / 丸図形

役割：
- ポップさ
- 軽やかさ
- 背景にリズムを作る
- 写真の余白を楽しくする

### 2. 波線 / 曲線 / フレーム

役割：
- 風
- 水
- 表情
- やわらかい動き
- 境界の揺らぎ

### 3. はじけるイメージ

役割：
- 見ていて楽しい空気感
- ファンサイトらしい明るさ
- 活動の広がり

## 8. 写真の扱い

- 写真はFVの最重要要素
- 人物の顔、視線、赤い衣装を主役として扱う
- 装飾は写真を邪魔しない
- 明るく、やわらかく、透明感のあるトーンに整える
- 写真フレームは大きな角丸または曲線的なフレームにする
- 複数写真をスライド表示できる設計にする

## 9. サイト構成

1. First View
2. 活動紹介
   - 舞台
   - 映像
   - イラスト
   - 執筆・詩・コラム
3. Photo / Gallery
4. News / Info
   - 公演予定
   - 出演情報
5. Contact & SNS
   - お問い合わせフォーム
   - SNSリンク
   - 依頼しやすい活動内容の説明
6. Footer

## 10. 実装時の基本方針

- まず静的HTML/CSS/JSで再現
- その後WordPressテーマへ組み込み
- FV写真は将来的に複数枚管理できるようにする
- NewsはWordPress投稿タイプで管理できるようにする
- Galleryはカスタム投稿タイプまたはメディア管理を想定
- Contactはフォームプラグインまたは独自フォームで実装
