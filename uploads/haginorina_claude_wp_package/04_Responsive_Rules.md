# Responsive Rules：レスポンシブ設計ルール

## 1. 基本方針

PCでは「左テキスト・右写真」の横並びで、余白と装飾を大きく使う。  
スマホでは「読みやすさ」と「写真の顔が欠けないこと」を最優先にする。

## 2. PC：1024px以上

### レイアウト

- Header: 横並び
- Hero: 2カラム
  - 左：42%
  - 右：58%
- FV高さ：`min-height: 100svh`
- テキストは左寄せ
- 装飾は画面全体に広く配置

### 注意点

- 写真の顔が右端に寄りすぎない
- ナビボタン同士の余白を十分に取る
- 装飾は四隅と写真周辺に配置し、文字周辺は控えめにする

## 3. Tablet：768px〜1023px

### レイアウト

- Headerは横並びを維持、ただしナビのgapを小さくする
- Heroはやや縦積みに近づける
- 写真を横幅いっぱいに近づける
- テキストは上または左上にまとめる

### 注意点

- 装飾を30%程度減らす
- 大きな円は画面外にはみ出させる
- 写真上にテキストを重ねすぎない

## 4. SP：767px以下

### レイアウト

推奨順序：

1. Logo
2. Main title block
3. Hero image
4. CTA
5. SNS
6. Nav / Section links

### 仕様

- Header navはハンバーガーまたは横スクロールpill
- H1は画面幅に合わせて縮小
- リード文は3行以内を維持
- CTAは横幅100%に近いサイズでもOK
- メイン画像は角丸を維持しつつ、顔が中心に来るように `object-position` を調整

### 装飾

- PCの50%以下に削減
- 文字周辺の装飾は最低限
- 大きな円は背景として薄く使う
- ドットマトリクスは1〜2箇所まで

## 5. スマホで守ること

- 名前「はぎのりな」が必ず読める
- CTAがFV内に入る
- 写真の顔が欠けない
- 装飾でテキストを邪魔しない
- 横スクロールを発生させない

## 6. CSSブレークポイント例

```css
:root {
  --container-x: clamp(40px, 5vw, 88px);
}

@media (max-width: 1023px) {
  :root {
    --container-x: 32px;
  }
}

@media (max-width: 767px) {
  :root {
    --container-x: 24px;
  }

  .hero {
    grid-template-columns: 1fr;
  }

  .hero-decoration {
    opacity: .55;
  }
}
```
