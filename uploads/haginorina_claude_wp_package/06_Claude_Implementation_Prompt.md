# Claude実装依頼プロンプト

以下の資料をもとに、はぎのりな様公式サイトのファーストビューを高品質にHTML/CSS/JSで実装してください。

最終的にはWordPressで実装予定ですが、まずは静的HTML/CSS/JSとして再現してください。  
あとからWordPressテーマに分解しやすいように、構造・命名・CSS変数を整理してください。

## 実装してほしい内容

### 1. ファーストビュー

- 左側にコピー・名前・リード文・CTA・SNS
- 右側にメイン写真
- 上部にロゴとナビゲーション
- 背景に赤・黄・白・淡色の丸図形、ドット、リング、曲線装飾
- 写真は大きな角丸フレームで表示
- PCでは横並び、SPでは縦積み

### 2. コピー

ロゴ：
- Haginorina
- Official Fan Site

肩書き：
- フリーの役者 / たまにモデル

メインタイトル：
- はぎのりな

リード文：
- 表現することが大好きです。
- 舞台や映像、いろんな場所で
- 皆さんと出会えますように。

CTA：
- 最新情報をチェック

ナビ：
- 活動紹介
- Photo / Gallery
- News / Info
- Contact & SNS

### 3. デザインの重要ポイント

- 写真と名前が主役
- 装飾は世界観を作るが、情報の邪魔をしない
- 子どもっぽくなりすぎず、公式感を保つ
- チューリップレッド `#E63946` とスプリングイエロー `#F4D35E` を主軸にする
- 背景は白〜淡いウォームグレー
- フォントは丸みがあり可読性の高いものを使用

### 4. レスポンシブ

PC：
- 2カラム
- 右に大きな写真
- 左にテキスト

SP：
- 名前 → 写真 → CTAの順で見せる
- 写真の顔を欠けさせない
- 装飾量を減らす
- 横スクロールを発生させない

### 5. アニメーション

控えめで上品にしてください。

- 装飾円のゆるい浮遊
- CTA hover
- 写真スライド対応可能な構造
- scroll cue

### 6. 出力形式

以下の3ファイルで出力してください。

- `index.html`
- `style.css`
- `script.js`

### 7. WordPress化を見据えた注意

- セクションごとにコメントを入れてください
- Heroは後で `template-parts/hero.php` に切り出せる構造にしてください
- CSS変数を使ってください
- 画像パスは `/assets/images/` 想定にしてください
- SNSリンク・CTAリンクは後から差し替えやすくしてください
- NewsやGalleryに発展しやすい構造を意識してください

## 品質基準

- FV画像の雰囲気を忠実に再現する
- 余白を詰めすぎない
- 装飾を増やしすぎない
- 文字の可読性を最優先
- PC / SPともに破綻しない
- WordPress化しやすいHTML構造にする
