# Assets List：素材一覧

## 1. 必須素材

### メインビジュアル写真

用途：
- FV右側の主役画像
- 将来的にスライダーで複数枚表示予定

必要形式：
- WebP推奨
- JPG可
- 横長写真推奨
- 高解像度

推奨ファイル名：
- `hero-main-01.webp`
- `hero-main-02.webp`
- `hero-main-03.webp`

注意：
- 顔周りが欠けない写真を使用
- 赤い衣装が見える写真はFVとの相性が高い
- 明るく透明感のあるトーンに整える

## 2. ロゴ

用途：
- Header
- Footer
- favicon可能性

必要形式：
- SVG推奨
- PNG透過可

推奨ファイル名：
- `logo-haginorina.svg`
- `logo-haginorina-white.svg`

## 3. 花 / チューリップアイコン

用途：
- ロゴ横
- バッジ
- 装飾

必要形式：
- SVG推奨

推奨ファイル名：
- `icon-tulip.svg`

## 4. SNSアイコン

用途：
- FV下部
- Contact & SNS
- Footer

必要SNS：
- X
- Instagram
- YouTube

推奨形式：
- SVG

推奨ファイル名：
- `icon-x.svg`
- `icon-instagram.svg`
- `icon-youtube.svg`

## 5. 装飾素材

CSSで再現できる場合はCSS優先。  
複雑なドットや手描き風ラインのみ画像化を検討。

### 種類

- 丸図形
- ドットマトリクス
- リング
- 斜め丸棒
- 曲線
- 淡い円形グラデーション

## 6. favicon / OGP

必要に応じて準備。

- `favicon.ico`
- `apple-touch-icon.png`
- `ogp.jpg`
