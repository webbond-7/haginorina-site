# はぎのりな Official Fan Site — WordPress テーマ

静的な試作(`../*.html`)を WordPress のテーマにしたもの。見た目は試作と同じで、
ニュース・公演予定・役のカード・写真・お問い合わせを管理画面から更新できる。

## 入れ方(公開するサーバーで)

1. `haginorina/` を zip にする(`cd wp-theme && zip -r haginorina.zip haginorina -x "*.DS_Store"`)
2. 管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロード で zip を入れ、有効化
3. ツール → はぎのりな 初期データ → 「初期データを入れる」を1回押す
   - ページ(ホーム・News / Info・活動紹介・Photo / Gallery・Contact & SNS)、ニュース8件、公演予定3件、役のカード4枚、写真17枚が入る
   - 表示設定(トップ=ホーム、投稿ページ=News / Info)とパーマリンク(投稿名)も設定する
   - 見本の「Hello world!」と「サンプルページ」はゴミ箱へ移す(チェックを外せば残る)
   - 2回押しても同じものは増えない
4. 外観 → カスタマイズ → はぎのりな 設定 で、お問い合わせの送信先を確認(初期値 sobo74sobo@gmail.com)
5. **メールが届くかを必ず試す。** レンタルサーバーの初期状態では、WordPress のメールが
   迷惑メール扱いになったり届かなかったりする。届かないときは「WP Mail SMTP」などで
   送信元を正しく設定する。届かなくても、管理画面の「お問い合わせ履歴」に控えは残る

## 更新のしかた(管理画面)

| 載せたいもの | どこから | 表示される場所 |
|---|---|---|
| お知らせ | 投稿 → 新規追加。カテゴリ(舞台 / 配信・映像 / 演出・脚本 / お知らせ)を1つ選ぶ。アイキャッチを入れると記事の上に出る | トップの News、News / Info、カテゴリ別一覧 |
| 公演予定 | 公演予定 → 公演予定を追加。初日・千秋楽・会場・関わり方・リンク先 | トップの「次の舞台」の帯(まだ終わっていない一番近いもの)、News / Info の Upcoming(近い順に3件)。終わった公演は自動で消える |
| 役のカード | 役のカード → カードを追加。タイトル=役名、アイキャッチ=写真、裏面の作品名・期間・劇場 | 活動紹介の Roles。「並び順」の小さい順 |
| 写真 | 写真 → 写真を追加。アイキャッチ=写真、分類(STAGE / FILM / MODEL / OFFSHOT) | Photo / Gallery(全部)、トップの Gallery(先頭8枚) |

| 活動紹介の「主な出演作」「撮影の内容」 | 固定ページ → 活動紹介 を編集。下の「活動紹介の一覧」に1行1項目で書く。空欄なら元の内容のまま | 活動紹介の3枚のカード |
| トップの最初の写真3枚・プロフィール | 外観 → カスタマイズ → トップページ。空欄なら元の写真と文章のまま | トップ |

写真で顔が切れるときは、それぞれの編集画面(またはカスタマイズ)の「顔の位置」を変える。

### 増えたときの表示

- ニュースは1ページ10件。11件目から「1 2 3 … 次へ」のページ送りが出る(カテゴリ別・月別も同じ)
- News / Info とカテゴリ別の一覧に「月別」の選択欄。選ぶと /2026/09/ のような月ごとの一覧へ移る
- トップの News は新しい4件、トップの Gallery は並び順の先頭8枚
- Photo / Gallery は最初に24枚、「MORE PHOTOS」で24枚ずつ足す。分類で絞り込むと、その分類は全部出る
- 終わった公演予定は、消さなくても表示から外れる

## ファイル

- `functions.php` … 読み込みと基本設定
- `inc/helpers.php` … テンプレートで使う関数(URL、日付、ニュース1行、写真タグ)
- `inc/post-types.php` … 公演予定・役のカード・写真・お問い合わせ履歴
- `inc/meta.php` … 入力欄。項目を増やすときは `hn_meta_fields()` に足す
- `inc/customizer.php` … お問い合わせの送信先
- `inc/contact.php` … フォームの送信(nonce・人に見えない罠の欄・3秒未満の送信を捨てる・60秒の連投制限・控えの保存)
- `inc/editable.php` … トップの写真・プロフィール・活動紹介の一覧(管理画面から直せる箇所)
- `inc/private-mode.php` … 公開前モード
- `date.php` … 月ごとの一覧
- `inc/seed.php` … 初期データ
- `front-page.php` / `home.php` / `category.php` / `single.php` / `page-works.php` / `page-gallery.php` / `page-contact.php` … 各ページ
- `template-parts/` … 次の舞台の帯、役のカード、公演予定カード
- `assets/` … 試作と同じ CSS・JS・画像(main.js はギャラリーの拡大表示を絞り込みに対応させた版)

## 手元で動かす(確認用)

WordPress Playground で、データベースなしに動かせる。

```
npx @wp-playground/cli@latest server --port=9400 \
  --mount="$(pwd)/haginorina:/wordpress/wp-content/themes/haginorina" \
  --blueprint=blueprint.json
```

`blueprint.json` はテーマの有効化と `hn_seed_run( true )` の実行だけを書いたもの(作業ログ参照)。
管理画面は http://127.0.0.1:9400/wp-admin/ (admin / password)。止めると中身は消える。
